MariaDB Export

Export Home Assistant recorder history from MariaDB or MySQL.

What it writes

States, events, hourly statistics, 5-minute statistics, and recorder runs, as CSV, JSON, or JSON Lines. A custom export runs one read-only SELECT. Files land in config/mariadb_export/.

Use it in Home Assistant

Add the integration, then call the export action.

action: mariadb_export.export
data:
  dataset: statistics
  start: "{{ (now() - timedelta(days=31)).isoformat() }}"
  format: csv

Give the database user SELECT only. The action does not change recorder tables.

Install

  • Publish this repository on GitHub.
  • Add it in HACS as an integration, or copy custom_components/mariadb_export.
  • Restart Home Assistant and add MariaDB Export.
